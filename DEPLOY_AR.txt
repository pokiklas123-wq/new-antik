السيرفر ليس منشورًا تلقائيًا.
ارفع محتويات هذه الحزمة إلى مستودع خدمة Node.js عندك، ثم استخدم:
Build: npm ci --omit=dev
Start: npm start
Node: 20 أو أحدث
Health check: /health
إذا رفعت المشروع الكامل فاختر Root Directory=server.
بعد النشر ضع رابط HTTPS في شاشة تطبيق APK الأولى.
لتشغيل الفحوص: npm ci ثم npm test.
